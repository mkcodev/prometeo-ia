# Prometeo

El fuego de la IA, para quien construye.

Guía open source, en español, para que un desarrollador web pase de "uso ChatGPT" a AI Engineer capaz de llevar productos con LLMs a producción. Es tres cosas a la vez: un mapa de habilidades con prerrequisitos, un libro de texto interactivo donde cada concepto se entiende manipulándolo, y un cuaderno de estudio personal con progreso, rachas, repaso espaciado y apuntes.

## Principios

- **Sin API key.** Todas las visualizaciones funcionan en el navegador con datos de ejemplo deterministas.
- **Sin rastreo.** No hay analítica ni cuentas. Tu progreso y tus apuntes se guardan en tu navegador y no salen de él; puedes exportarlos e importarlos en JSON.
- **Fuentes oficiales.** Cada concepto enlaza a documentación oficial, indica el idioma de cada enlace y muestra su fecha de última revisión.
- **Sin atarse a un proveedor.** Se enseña el concepto y cómo se llama en los principales.
